# Jev Puyo Lab

ぷよぷよ風の落ちものパズルを、人間・ルールAI・TypeSafe Jevでプレイして比較する実験場です。既存ゲームの画像・音源・ロゴは使用せず、オリジナルの描画で基本的な連鎖ルールと操作感を再現しています。

## 起動

リポジトリ直下の `.env` にAPIキーを設定します。

```env
LOLIPOP_AI_GATEWAY_API_KEY=...
```

```bash
cd 2026-04-12-puyopuyo
npm start
```

<http://localhost:4174> を開きます。

## プレイヤー

- `HUMAN`：左右移動、回転、落下をキーボードで操作
- `HEURISTIC`：得点、連鎖候補、高さ、穴、凹凸を使うローカルAI
- `JEV DIRECT`：全合法手をひとつのChoiceとしてJevに選ばせる
- `JEV JURY`：合法手ごとに独立したNoul判定を行い、最高確率の手を採用する

同じシードを使うと同じぷよ列で比較できます。

## 実装したルール

- 6列×12段＋隠し1段
- 4色、同色4個以上で消去
- 連鎖倍率・色数ボーナス・同時消しボーナス
- 全消しボーナス2100点
- NEXT／NEXT2
- 中央上段が埋まるとゲームオーバー
- 最大連鎖、判断時間、確信度、手ごとのログ
