# 言葉喰い — Jevで育つ謎の生物

文章を食べさせると、Jevが意味や文脈を複数の軸で判定し、その結果を遺伝子として蓄積する小さな生物育成アプリです。

## 起動

リポジトリ直下の `.env` にAPIキーを置きます。

```env
LOLIPOP_AI_GATEWAY_API_KEY=...
```

その後、プロジェクト内で起動します。

```bash
npm start
```

ブラウザで <http://localhost:4173> を開いてください。

## 遊び方

1. 今日あったこと、コード、詩、愚痴など、好きな文章を入力する
2. 「食べさせる」を押す
3. Jevが温度・活力・論理性・混沌度・生息域・気質・突然変異の兆候を判定する
4. 判定が生物の色、形、目、角、動きに少しずつ蓄積する

成長記録はブラウザの `localStorage` に保存されます。「新しい卵」からリセットできます。

## 構成

- Node.jsの小さなHTTPサーバー（外部依存なし）
- ロリポップ！AIゲートウェイ `POST /v1/systemone`
- モデル `typesafe/jev-latest`
- ブラウザにはAPIキーを渡さないサーバーサイド構成
- SVGとCSSによる生成的な生物表現
